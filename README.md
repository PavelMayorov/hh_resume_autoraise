# HH Resume Autoraise

## Описание
Сервис для автоматического поднятия резюме в поисковой выдаче платформы [HeadHunter](https://hh.ru/) каждые 4 часа.

Представляет собой альтернативу платной услуге [Продвижение.LITE](https://hh.ru/applicant/services/payment?from=landing&package=lite) от HeadHunter.

## Требования

- Python 3.11

## Инструкция для запуска

### Локальный запуск

1. Клонирование репозиотрия:

``` git clone git@github.com:PavelMayorov/hh_resume_autoraise.git ```

2. Создание и активация виртуального окружения:

   ``` python -m venv .venv ```

   ``` . .venv/bin/activate ```

4.  Установка зависимостей:

   ``` pip install -r requirements.txt ```

5. Конфигурация:

Скопировать шаблон конфигурационного файла

```cp config.d/config.yml.example config.d/config.yml```

Отредактируйте config.d/config.yml, указав необходимые параметры.

5. Запуск сервиса:

   ``` python3.11 -O -m src ```

### Запуск в контейнере (Docker)

Репозиторий содержит Dockerfile и пример docker-compose.yml для запуска сервиса в Docker.

## Архитектура и функциональность

Сервис состоит из следующих компонентов:

•   Telegram-бот:  Интерфейс для управления аккаунтами и резюме через Telegram.

•   Планировщик:  Автоматически поднимает резюме в поисковой выдаче HeadHunter.

### Telegram-бот

Предоставляет следующие команды:

•   **/help**:  Выводит список всех доступных команд бота с описанием.

•   **/add_account**:  Добавляет учетные данные аккаунта HeadHunter (логин и пароль) для управления резюме.

1. Запрашивает логин (номер телефона) аккаунта
2. Запрашивает пароль аккаунта

•   **/add_resume**:  Добавляет резюме из указанного аккаунта в список на автоматическое поднятие.
1. Запрашивает логин аккаунта HeadHunter
2. Предоставляет список доступных резюме для выбора

•   **/del_resume**:  Удаляет резюме из списка на автоматическое поднятие.
1. Запрашивает логин аккаунта HeadHunter
2. Предоставляет список резюме, добавленных на поднятие, для выбора

•   **/get_resumes**:  Выводит список всех резюме, находящихся в списке на автоматическое поднятие, с указанием аккаунтов.

### Планировщик

•   Периодически, в соответствии с настройкой _resume_check_frequency_ в конфигурационном файле, выполняет следующие действия:
1. Запрашивает список резюме из базы данных
2. Проверяет доступность каждого резюме для поднятия в соответствии с правилами HeadHunter
3. Поднимает доступные резюме в поисковой выдаче
